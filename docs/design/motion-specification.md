# Nehemiah Organism Motion Specification

| State | Purposeful motion | UI consequence |
|---|---|---|
| Resting | Slow breathing and quiet internal circulation | No contextual panel competes for attention |
| Listening | Organism expands slightly; internal paths orient toward the command source | Listening prompt replaces the resting question |
| Focus Surfaced | One major internal path accelerates while surrounding motion quiets | Founder focus and protected window appear |
| Decision Required | Evidence paths converge and one luminous thread extends to the decision field | One Founder decision appears |
| Action Underway | Light travels outward through the chosen path | Decision field gives way to action status |
| Proof Created | Movement settles into greater coherence; core illumination persists | Founder-approved proof language appears |

## Motion Rules

- Motion communicates system state; it is never decorative.
- Only one outward signal thread may be visible at a time.
- No red alert animation is used for ordinary delay or uncertainty.
- `prefers-reduced-motion` collapses every animation to its final readable state.
