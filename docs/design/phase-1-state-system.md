# Nehemiah Phase 1 State System

## Approved Visual Direction

Nehemiah is a living private intelligence artifact for the Founder. The organism remains visually dominant. The interface only surfaces context that changes the Founder’s next consequential action.

## Six States

| State | Purpose | Organism behavior | Permanent UI | Contextual UI | Exit trigger |
|---|---|---|---|---|---|
| Resting | Observe quietly without demanding attention | Slow internal circulation; no outbound path | Identity, organism, command field | None | Founder input or material signal |
| Listening | Receive voice, text, files, or system signals | Internal strands orient toward the input source | Identity, organism, command field | Listening acknowledgement | Input complete |
| Focus Surfaced | Identify what matters most and why | One pathway strengthens; surrounding motion reduces | Today’s Focus, protected window | Why this comes first | Founder opens focus or a decision is required |
| Decision Required | Prepare a Founder-owned consequential decision | Evidence converges; one luminous thread forms to decision field | Focus context, decision field, command field | Evidence and alternatives on demand | Founder chooses a decision action |
| Action Underway | Coordinate approved visible action | Stable outward flow through chosen path | Action owner, deadline, dependencies | Exceptions and blockers | Proof received or action prevented |
| Proof Created | Preserve evidence and compound learning | Pattern settles into lasting coherence; proof point persists | Proof record, lesson, continuation | Source trace | Founder closes review or next signal arrives |

## Engaged-State Copy

- Primary question: **What matters most now?**
- Decision causal chain: Why This Surfaced → What Could Become Possible → The Tradeoff → Visible Action → Proof Required.
- CTA: **Open Decision**
- Founder authority line: **Nehemiah prepares the decision. You choose the direction.**

## Subtraction Rules

The permanent engaged-state canvas must not include:

- Bottom energy/focus/commitments status strip
- Personal Standard block
- Rail quote or decorative signature
- Unexplained metrics
- Multiple simultaneous decision cards
