# Nehemiah Command v0.12.0 — Preparation Evidence Attachments

## Outcome

Decision-preparation requirements now hold structured evidence rather than relying only on written assertions.

## Capabilities

- Attach a link, file reference, or source record to any readiness requirement.
- Preserve evidence title, reference, owner, due date, creation time, and verification status.
- Verify evidence with a named verifier and timestamp.
- Reject malformed links and incomplete evidence records.
- Prevent the Evidence readiness dimension from resolving until at least one attached source is verified.
- Display evidence and verification state inside the Decision Preparation Workspace.

## Governance

- Text alone cannot resolve the Evidence dimension.
- Verification records who verified the source and when.
- This release stores attachment metadata only; actual file upload and cloud storage begin in the durable-record phase.
- The Founder remains the final decision authority.
