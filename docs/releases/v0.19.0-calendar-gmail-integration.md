# Nehemiah Command v0.19.0 — Calendar and Gmail Integration

## Purpose

Introduce governed Google Calendar and Gmail signal ingestion so Nehemiah can organize commitments, communications, and decision requests without granting integrations access to Founder-private memory or autonomous action authority.

## Delivered

- Dedicated authenticated Calendar ingestion route: `POST /api/integrations/google-calendar`.
- Dedicated authenticated Gmail ingestion route: `POST /api/integrations/gmail`.
- Canonical normalization for Calendar commitments and Gmail communications.
- Decision-request classification for Gmail messages containing approval, authorization, sign-off, or unblock language.
- Founder-only agenda API: `GET /api/founder-agenda`.
- Founder Agenda panel displaying commitments, communications, and decision requests.
- Integration provenance through integration ID, external ID, occurred time, received time, type, summary, and bounded payload.
- Duplicate protection through the existing integration-signal database constraint.
- Existing integration authentication, distributed rate limiting, security audit events, and authorization boundaries reused.

## Privacy and governance

- Gmail message bodies are not stored by the normalizer.
- Only subject, sender, bounded snippet, thread ID, and labels are preserved.
- Calendar ingestion stores event metadata needed for commitments; it does not receive Founder-private memory.
- Integrations append signals only. They cannot read Founder-private or enterprise records.
- Nehemiah does not send email, alter calendar events, accept invitations, or approve decisions in this release.
- The Founder Agenda organizes evidence; the Founder remains the decision authority.

## Production connection boundary

This release provides the production ingestion contract and Founder experience. Google OAuth subscription setup, webhook verification, token refresh, and provider-console credentials require the actual Google Workspace deployment environment and are documented in `docs/integrations/google-workspace.md`.
