# Nehemiah Command v0.18.0 — AI Orchestration

## Purpose

Introduce live, governed model calls for Founder decision preparation without allowing AI to decide, execute, alter memory, or bypass the Founder decision gate.

## Delivered

- Authenticated `POST /api/ai/decision-preparation` route.
- OpenAI-compatible Responses API provider with configurable model and base URL.
- Strict JSON-schema output contract for decision preparation.
- Bounded request and context validation.
- Explicit tool allowlist; this release executes no tools.
- Founder-authority system policy and anti-execution boundary.
- Retry behavior for transient provider failures and rate limits.
- Abort timeout and fail-closed malformed-output handling.
- Auditable orchestration metadata without prompt or secret leakage.
- Security audit events for successful and failed orchestration.
- Live decision-chamber card for governed AI preparation.
- Production readiness checks for model credentials.

## Structured output

Each preparation contains why the decision matters now, what could become possible, tradeoffs, three moves ahead, evidence requirements, assumptions, risks with mitigations, a Founder question, and a bounded confidence score.

## Governance

AI preparation is advisory. It cannot approve, reject, send, publish, commit resources, execute tools, or write Founder memory. The existing readiness and decision gates remain authoritative.

## Configuration

- `NEHEMIAH_AI_API_KEY`
- `NEHEMIAH_AI_MODEL`
- `NEHEMIAH_AI_BASE_URL` (optional)

No provider credential is sent to the browser.
