# MiP Official Legendary AI Roster

Canonical organization chart and machine-readable roster for MiP's AI-operated,
human-governed Behavioral Financial Transformation enterprise.

**Version 1.0 · Founder Approved · 2026-07-27**

> Distinct powers. One system. Proof change is possible.

## Files

All five files are the **same** roster in different representations. The JSON is
the canonical machine-readable source; the others are derived views kept in sync.

| File | Format | Use |
|---|---|---|
| `mip_official_legendary_ai_roster_v1_0.json` | JSON | Canonical machine-readable source |
| `mip_official_legendary_ai_roster_v1_0.yaml` | YAML | Human-editable machine-readable mirror |
| `mip_official_legendary_ai_roster_v1_0.md` | Markdown | Readable reference |
| `mip_official_legendary_ai_roster_v1_0.mmd` | Mermaid | Org-chart diagram (renders on GitHub) |
| `mip_official_legendary_ai_roster_v1_0.dot` | Graphviz DOT | High-fidelity org-chart render |

## Structure

- **Founder** — Constitutional and final enterprise authority.
- **Executives** (report to Founder): **Nehemiah** (AI Operations CEO /
  Enterprise Orchestrator), **Anakin** (Human Transformation & Market
  Experience), **Mercado** (Product, AI & Technology).
- **32 agents**, each reporting to one executive, with a role, superpower, value
  to MiP, and a Council of Rivals (doctrine sources and reviewers, not separate
  operating agents).

Reporting edges are authoritative.
