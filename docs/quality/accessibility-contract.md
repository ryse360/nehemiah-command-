# Accessibility Contract

Nehemiah Command targets WCAG 2.2 AA for the Founder desktop experience.

Required controls:
- Skip link to the primary command surface
- One main landmark and labelled navigation
- Accessible names for icon-only controls
- Visible keyboard focus
- Minimum 44px interactive targets
- Reduced-motion behavior without lost state information
- Responsive operation at 320px CSS width and 200% zoom
- Status changes announced through a polite live region

Automated tests protect the contract. Manual keyboard, zoom, contrast, screen-reader, and reduced-motion checks remain part of each production rehearsal.
